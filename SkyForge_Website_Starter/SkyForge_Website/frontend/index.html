✦ FAQ

Perguntas que o site deve responder antes do cliente perguntar.

Esta secção deixa o produto mais credível e ajuda visitantes a entenderem exatamente o que é o SkyForge.

SkyForge é um render engine completo?

Nesta versão, SkyForge está posicionado como uma ferramenta de sky, HDRI, lookdev e pipeline para preparar ambientes e iluminação. Depois pode evoluir para motor próprio ou bridge avançado com Blender.

O site já está pronto para vender o produto?

A estrutura visual e comercial já está forte. Para vender de verdade, o próximo passo é ligar botões, criar página de download, screenshots reais, vídeo demo e formulário de beta.

Dá para integrar com o projeto SkyForge em Node.js?

Sim. Esta interface pode virar a landing page principal do frontend e depois conectar ao backend Express que já começaste.

Posso adaptar para HTML simples?

Sim. O layout já está em HTML, CSS e JavaScript puro para poderes abrir diretamente no navegador.

O SkyForge será vendido como addon ou app?

A melhor estratégia é ter os dois: uma app/website para presets, conta, downloads e documentação; e um addon Blender para aplicar tudo diretamente na cena.
